# NeonHades2

NeonHades2 is an unofficial passion project that aims to build the most accurate guide to *Hades II* using information checked against the game.

## Data boundary

This repository will contain NeonHades2's own source code and documentation.
Game files and game-derived data will remain outside the repository.

Game owners can reproduce the local source and runtime acquisitions with the [data tooling guide](/project/data/README.md).
